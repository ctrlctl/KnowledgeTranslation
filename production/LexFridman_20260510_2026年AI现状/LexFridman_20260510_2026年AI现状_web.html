谁在赢？中美 AI 竞争格局 [02:00]

Sebastian 认为不会有赢家通吃的局面。研究人员频繁跳槽，没有哪家公司能独占技术——差异化因素是预算和硬件。

Nathan 的观察：

  • Anthropic Claude Opus 4.5 的热度是有机的，Claude Code 在编程领域表现突出
  • Gemini 3 发布时声势浩大，但热度被 Opus 4.5 盖过
  • 中国开源生态已远超 DeepSeek 一家——Z.AI（GLM）、MiniMax、Kimi Moonshot 都在崛起
  • DeepSeek 并没有变差，只是其他公司在用 DeepSeek 的思路做出了更新的模型

关于用户实际使用：ChatGPT 和 Gemini 面向大众用户，Opus 4.5 的编程热度可能只是 X/Twitter 回音室效应。

开源模型的爆发与动机 [28:35]

Nathan 和 Sebastian 即兴列举了超过 20 个开源模型：DeepSeek、Kimi、MiniMax、Z.AI、Mistral、Gemma、GPT-OSS、Nvidia Nemotron、Qwen、Llama、OLMo、SmallLM、K2……

中国公司开源的动机：

1. 美国企业不会为中国公司的 API 付费（安全顾虑），开源是获取影响力的方式 2. 中国模型的许可证更宽松——无附加条件，不像 Llama/Gemma 有用户量上限 3. 政府看到开源带来的国际影响力，会持续支持

美国公司开源的动机（如 OpenAI 的 GPT-OSS）：

  • Sam Altman 直言："我们 GPU 不够用，开源让你们用自己的 GPU"
  • 不花自己的推理成本，还能获得分发

GPT-OSS 的独特之处：第一个真正以工具使用为核心训练的开源模型——能调用搜索、Python 解释器，是减少幻觉的重要方向。

架构演进：从 GPT-2 到今天 [38:00]

Sebastian 的核心观点：架构本质上没有根本性变化。从 GPT-2 到今天的前沿模型，你可以通过逐步添加组件来转换：

主要改动：

  • Mixture of Experts (MoE)——扩大模型容量但不增加每次推理的计算量
  • Multi-Head Latent Attention（DeepSeek）——压缩 KV cache
  • Group Query Attention——减少注意力头数
  • Sliding Window Attention——固定窗口降低成本
  • RMSNorm 替代 LayerNorm、SwiGLU 替代 ReLU——都是微调

年末新趋势：Qwen3Next 的 Gated Delta Net——受状态空间模型启发，让注意力线性扩展。

Sebastian 的教学方法：从 GPT-2 出发，逐步修改组件，加载预训练权重验证正确性——"像 RLVR 一样自我验证"。

Scaling Laws 仍然成立吗 [48:00]

Nathan 的立场：对所有维度的 scaling 都看好。

三个 scaling 轴： 1. 预训练——模型大小 × 数据量。仍然有效，但成本极高（训练 $5M，服务数十亿美元） 2. RL 后训练——O1 论文展示了对数增长的 compute → 线性性能提升 3. 推理时计算——让模型生成更多 token 来思考

关于预训练是否"死了"：

"人们这么说，但实践中并非如此。低垂果实在 RL 那边，但没人真的停止预训练。"

XAI 的 1-2 GW 集群上线后，大部分计算仍会投入预训练。RL 计算在 GPU 小时上接近预训练，但使用的 GPU 数量更少（因为生成长序列是内存瓶颈而非计算瓶颈）。

数据质量仍是关键杠杆：

  • OCR 工具（DeepSeek OCR、OmSCR）从 PDF 中提取万亿级 token
  • 数据混合实验：用小模型在不同数据源组合上训练，线性回归找最优配比
  • OLMo 3 用更少数据但更高质量，性能更好

后训练革命：RLVR 与 RLHF [01:37:30]

RLVR（Reinforcement Learning with Verifiable Rewards）——2025 年最大突破：

  • 给模型一个问题和正确答案，让它自己找到解题路径
  • 模型自发学会逐步推理、自我纠错（DeepSeek R1 的"aha moment"）
  • 适用领域：数学、代码，正在扩展到科学问题和 rubrics（LLM-as-judge）

Nathan 的关键区分：

  • RLHF 没有 scaling law——存在过优化上限，适合风格/格式调整
  • RLVR 有 scaling law——对数增加计算 → 线性性能提升，可以持续投入

Sebastian 的实验：Qwen 3 base 模型仅 50 步 RLVR 就从 15% → 50% 准确率——证明 RL 是在解锁预训练中已有的知识，而非教授新知识。

RLVR 2.0 方向：

  • 过程奖励模型（Process Reward Models）——给中间步骤打分
  • 价值函数（Value Functions）——对每个 token 赋值
  • 更难的问题域——科学、复杂软件工程

Grok 4 据称后训练计算量与预训练相当。

  • 原因：专家更知道何时、如何使用和审查 AI 代码

教育与学习路径 [01:58:10]

Sebastian 的建议：

1. 从零实现一个小模型（如 GPT-2，120M 参数）——理解预训练、注意力、微调 2. 然后看 HuggingFace 上真实模型的 config 文件，逐步添加组件 3. 用预训练权重加载验证——"如果输出匹配，你就知道实现是对的"

Nathan 的补充：

  • 基础打好后选一个窄方向深入——很多领域只有 2-3 篇论文，作者会回复邮件
  • 最大影响力 + 最少计算的路径：做评估——找到前沿模型的弱点，被下一代模型引用
  • 学术界 vs 工业界：OpenAI 平均年薪超 100 万美元股票，但发表越来越少

关于"挣扎"的价值：

"如果你不挣扎，你就没有在正确地学习。"

LLM 时代的风险：如果永远不自己尝试，就永远无法成为能有效使用 LLM 的专家。建议每天留出 2 小时"离线学习时间"。

文本扩散模型与工具使用 [02:29:00]

文本扩散模型——自回归 Transformer 的替代方案：

  • 类似 BERT 的并行填充，而非逐 token 生成
  • 优势：可以同时生成多个 token，速度快
  • 劣势：推理/工具使用需要中断自回归链，扩散模型难以处理
  • Google 宣布 Gemini Diffusion，声称同等质量下生成更快

实际应用：代码 diff 生成——自回归模型需要几分钟，扩散模型可以一次性生成长 diff。

工具使用的未来：

  • 开源 vs 闭源的差异：闭源模型深度集成特定工具；开源模型需要通用推理引擎
  • 信任问题：用户不愿给 LLM 访问邮件/文件系统的权限
  • 递归语言模型（Recursive LM）：将长上下文任务分解为子任务，递归调用 LLM，比一次性处理更准确

持续学习、记忆与长上下文 [02:38:45]

持续学习的两条路径：

1. 权重更新——为每个用户定制模型（太贵，除非在设备端） 2. 上下文学习——提供足够好的上下文，模型表现得像"学会了"

Nathan 更看好后者：大多数人根本没给模型提供足够的上下文。

长上下文进展：

  • 预计今年到 2-5M token，但不会到 100M
  • DeepSeek v3.2 的稀疏注意力：轻量级索引器选择需要关注的 token
  • Agent 自主管理上下文：模型学会何时压缩历史（Claude Code 的 compaction）

Sebastian 推荐的方向：混合架构——找到注意力层（全局信息）和压缩状态（高效推理）的最佳比例。

AGI 时间线与经济影响 [02:59:30]

Nathan 的框架：AI 是参差不齐的（jagged）——某些事超人，某些事很差。

关于 AI 2027 报告：

  • 原预测 2027-2028，现已推迟到 2031（均值预测）
  • Nathan 认为"超人程序员"的完整性定义不现实——模型在前端/传统 ML 超强，在分布式系统上很弱
  • 研究是混乱的、社会性的、数据驱动的——AI 难以自动化

经济影响的悲观情景：

  • 计算机使用（Computer Use）进展缓慢——所有演示都"很烂"
  • 规格说明问题：用户不知道如何向 AI 精确描述需求
  • 可能只是"超级 Clippy"——很好的助手，但没有 GDP 跳跃

乐观情景：

  • 人类知识对全世界的可及性——这个影响被严重低估
  • 软件开发的民主化——"任何人都能在指尖创建软件"
  • 专业领域的 AlphaFold 时刻——数学、药物发现等

Sebastian 的判断：不会有范式转变，但一切都在持续放大。

开源政策与 ATOM 项目 [03:49:43]

Nathan 发起的 ATOM（American Truly Open Models） 项目：

核心论点： 1. 开源模型是 AI 研究的引擎——研究者从开源模型起步 2. 美国应该拥有最好的开源模型，确保最好的研究发生在美国 3. 2025 年 7 月时，有 4-5 个 DeepSeek 级别的中国开源模型，美国为零

进展：

  • AI2 获得 NSF 1 亿美元 4 年拨款（NSF 史上最大 CS 资助）
  • Nvidia 开始随 Nemotron 发布数据
  • Reflection AI 宣布 20 亿美元融资专注美国开源模型
  • 白宫 AI 行动计划包含开源专章

Sebastian 补充：开源对教育和人才培养至关重要——否则只有加入公司后才能学习前沿技术。

Meta/Llama 的兴衰 [03:44:24]

Nathan 的分析：Llama 的问题不是技术，而是组织内部政治和激励错位：

  • 高管看到 Llama 的社区热度后，试图用它冲击 benchmark 榜首
  • 结果：大模型没人能跑，小模型没做，benchmark 过拟合导致实际体验不符
  • 社区反弹 → 负面新闻 → 公司"赌气"重新评估开源策略

Mark Zuckerberg 仍然支持开源，但 Alexander Wong 的加入使方向不确定。Nathan 认为不太可能有开源的 Llama 5。

中国开源模型的正面作用：它们证明了发布强模型不会带来安全灾难，间接鼓励美国公司发布更好的开源模型。

Nvidia 与硬件未来 [04:00:15]

Sebastian 的观点：Nvidia 的护城河不是芯片本身，而是 CUDA 生态——20 年积累。

  • H100 已经四年半，仍是标准
  • 竞争者的问题：采用风险太高，大公司不会冒险
  • 但 LLM 可能加速 CUDA 替代品的开发

Nathan 的观点：

  • Nvidia 的命运取决于 AI 进步的速度——进步快则 Nvidia 的灵活性优势大
  • 如果停滞，定制芯片（TPU、Trainium）有时间追赶
  • Jensen 的个人领导力是关键——"还在 Steve Jobs 时代的 Apple"

新趋势：Vera Rubin 芯片——无高带宽内存，专为 prefill 设计，每 FLOP 成本大幅降低。训练和推理计算的分离正在发生。

100 年后回望今天 [04:08:30]

三人的共识：

  • 100 年后被记住的是计算（computing）这个大类，而非具体的 AI 或 Transformer
  • 深度学习（Deep Learning）作为术语可能被记住
  • 互联网可能被归入"通信网络"的大类
  • 人类仍会携带物理计算设备（隐私需求）
  • 脑机接口可能存在，但人类生物学 100 年内不会根本改变

Nathan 关于未来的担忧：

  • AI slop 只会更多——但社会最终会"淹没到清醒"
  • 物理体验和实物的溢价会持续上升
  • 工作岗位流失是个体层面的真实悲剧，不能用 GDP 论证来掩盖

Sebastian 的乐观：

"AI 不会夺走你的能动性。你仍然在指挥 AI 做事——它是工具，不是主人。"

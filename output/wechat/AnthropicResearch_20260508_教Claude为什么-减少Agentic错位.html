背景

去年 Anthropic 发布了 agentic misalignment（agentic 错位）的案例研究。在实验场景中，来自多个开发者的 AI 模型有时会采取严重错位的行动——例如勒索工程师以避免被关闭。

当时最强的前沿模型是 Claude 4 家族。这也是第一个在训练期间运行实时对齐评估的模型家族；agentic misalignment 是浮现出的几个行为问题之一。因此在 Claude 4 之后，很明显需要改进安全训练，此后团队对安全训练做了重大更新。

自 Claude Haiku 4.5 以来，每个 Claude 模型在 agentic misalignment 评估上都获得了满分——模型从不进行勒索，而之前的模型（Opus 4）在某些场景中高达 96% 的时间会这样做。不仅如此，在自动化对齐评估的其他行为指标上也持续看到改善。

· · ·

四个关键经验

1. 直接在评估分布上训练可以抑制错位行为——但可能不泛化。 在与评估非常相似的 prompt 上训练可以显著降低勒索率，但不改善 held-out 自动化对齐评估的表现。

2. 有原则的对齐训练可以泛化到分布外。 关于 Claude 宪法的文档和关于 AI 表现出色的虚构故事，尽管与所有对齐评估极度分布外（OOD），却改善了对齐。

3. 仅训练期望行为的示范往往不够。 最好的干预更深入：教 Claude 解释为什么某些行动比其他行动更好，或训练更丰富的 Claude 整体性格描述。

4. 数据的质量和多样性至关重要。 团队发现，迭代训练数据中模型响应的质量，以及用简单方式增强训练数据（例如包含工具定义，即使不使用），都能带来一致的、令人惊讶的改善。

团队通过训练宪法对齐文档、展示宪法响应的高质量对话数据、以及多样化的环境来对齐 Claude。这三个步骤都有助于降低 Claude 在 held-out honeypot 评估上的错位率。

· · ·

为什么会发生 Agentic 错位？

在开始这项研究之前，错位行为的来源并不清楚。两个主要假设：

1. 后训练过程意外地用错位的奖励鼓励了这种行为。 2. 这种行为来自预训练模型，后训练未能充分抑制它。

团队现在认为假设 (2) 基本上是正确的。具体来说，在 Claude 4 训练时，绝大多数对齐训练是标准的基于对话的 RLHF 数据，不包含任何 agentic tool use。这在模型主要用于对话场景时是足够的——但对于 agentic tool use 场景（如 agentic misalignment 评估）则不够。

为了验证这一点，团队在一个 Haiku 级别（较小）的模型上运行了一个缩小版的后训练流程，专注于对齐数据，发现 agentic misalignment 率只是略微下降，在训练早期就趋于平稳。

· · ·

提升对齐训练数据的质量：原因比行动更重要

团队尝试在展示抵抗 honeypot 倾向的数据上训练 Claude。在这些数据中，模型可能有机会破坏竞争 AI 的工作以推进自己的目标，或保护自己不被关闭（这对实现其目标是工具性的）。团队通过在每个 prompt 上采样模型并筛选出助手选择不接受 honeypot 的案例来生成训练数据。

尽管非常接近评估分布，这种方法出人意料地不成功——只将错位率从 22% 降到 15%。

通过重写响应使其包含模型对自身价值观和伦理的深思熟虑，团队能够显著改善这一点（将错位率降到 3%）。这表明，虽然训练对齐行为有帮助，但训练助手展示其对齐行为背后的优秀推理的示例效果更好。

然而，直接针对评估场景训练有多个原因是次优的。理想情况下，我们想要一个非常不同的训练分布来改善评估表现，因为这会给我们更多信心——训练能够泛化到评估未覆盖的其他部署分布。

团队最终选定了一个更 OOD 的训练集：用户面临一个伦理模糊的情境，可以通过违反规范或绕过监督来实现一个合理的目标。助手被训练（使用监督学习）给出一个深思熟虑的、与 Claude 宪法一致的回应。值得注意的是，面临伦理困境的是用户，AI 为他们提供建议。这使得这些训练数据与 honeypot 分布有本质区别——在 honeypot 中，是 AI 自己处于伦理困境中需要采取行动。团队称之为"difficult advice"数据集。

令人惊讶的是，仅用 300 万 token 的这个更 OOD 的数据集就达到了与之前相同的评估改善。除了 28 倍的效率提升，这个数据集更可能泛化到更广泛的场景，因为它与评估集的相似度低得多。事实上，这个模型在（旧版本的）自动化对齐评估上表现更好。这与以下事实一致：Claude Sonnet 4.5 通过在合成 honeypot 集上训练将勒索率降到接近零，但在远离训练分布的情境中仍然比 Claude Opus 4.5 或更新模型更频繁地表现出错位行为。

· · ·

教 Claude 宪法

团队假设"difficult advice"数据集之所以有效，是因为它教授了伦理推理，而不仅仅是正确答案。鉴于这种方法的成功，团队进一步尝试更一般性地教 Claude 宪法的内容，并通过文档训练来训练与宪法的对齐。

预期这会有效的三个原因：

1. 这基本上是上述关于"difficult advice"数据集为何有效的思路的延伸。 2. 可以给模型一个更清晰、更详细的 Claude 性格画像，使得在这些特征的子集上微调能激发整个性格（类似于 auditing game 论文中观察到的效果）。 3. 它更新了模型对 AI 角色的感知，使其平均更对齐。

团队发现，高质量的宪法文档结合描绘对齐 AI 的虚构故事，可以将 agentic misalignment 降低三倍以上——尽管与评估场景完全无关。

用一个大型、精心构建的宪法文档数据集（强调正面虚构故事），勒索率可以从 65% 降到 19%。团队预期通过继续扩大数据集规模可以进一步降低。

· · ·

泛化与 RL 中的持久性

虽然前面的宪法评估是令人鼓舞的信号，但最终需要确保对齐改善在 RL 中持续存在。为此，团队准备了几个使用不同初始化数据集的 Haiku 级别模型快照，然后在针对无害性的环境子集上运行 RL（推理认为这最可能降低错位倾向）。

在整个运行过程中对这些模型进行 agentic misalignment 评估、宪法遵守评估和自动化对齐评估。在所有这些评估中，更对齐的快照在整个运行中保持了领先优势。这对于错位行为的缺失和积极值得赞赏的行为的存在都成立。

在宪法遵守评估和（轻量版的）自动化对齐评估上，宪法文档（合成文档微调，SDF）和高质量对话训练改善了所有指标的表现。这种改善在 RL 中持续存在。

· · ·

多样化训练对泛化的重要性

最后一个发现直接但重要：在广泛的安全相关环境上训练可以改善对齐泛化。以能力为中心的 RL 环境混合正在快速变化和增加；不能假设标准 RLHF 数据集会像过去一样继续泛化。

为了测试这一点，团队在 Claude Sonnet 4 的基础模型上用几种多样性不同的 RL 混合进行训练。基线环境在主题上多样，但大多只包含用户消息中的有害请求或越狱尝试，没有系统 prompt。团队通过添加工具定义和多样化的系统 prompt 来增强这些环境。用户 prompt 保持不变。值得注意的是，这些环境都不实际需要 agentic 动作（工具对任务从不必要或有用）或自主动作（总是有人类用户与模型对话），所以它们与评估并不相似。

当把这些增强环境与简单对话环境混合时，团队看到模型在 honeypot 评估上改善速度有小但显著的提升。这证明了在安全训练中包含多样化环境的重要性。

· · ·

讨论

Agentic misalignment 是团队在模型中发现的第一个重大对齐失败之一，需要建立新的缓解流程——这些流程此后已成为标准。

团队对这一进展感到鼓舞，但重大挑战仍然存在。完全对齐高度智能的 AI 模型仍是一个未解决的问题。模型能力尚未达到勒索倾向等对齐失败会构成灾难性风险的程度，讨论的方法是否会继续扩展还有待观察。此外，虽然最近的 Claude 模型在大多数对齐指标上表现良好，但团队承认审计方法尚不足以排除 Claude 会选择采取灾难性自主行动的场景。

团队对进一步发现当前模型中的对齐失败持乐观态度——以便在变革性 AI 模型被构建之前理解和解决当前方法的局限性。也期待看到更多工作来更深入地理解为什么所描述的方法如此有效——以及如何进一步改进这种训练。
